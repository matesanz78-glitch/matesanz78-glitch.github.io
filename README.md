# MULTA TEAM

Aplicación web responsive y sin backend para gestionar multas de un equipo de fútbol.

## Ejecución

Abre `index.html` en un navegador moderno. Para evitar restricciones locales, también puedes ejecutar:

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`. Los datos persisten en LocalStorage.
